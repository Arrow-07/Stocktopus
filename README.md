## About

Stocktopus is an open-source desktop application designed to make inventory management simple, intuitive and efficient.

It allows users to organize items into hierarchical locations, categorize them, keep track of movements, and maintain a structured database of their inventory.

Built with Python and Qt, Stocktopus is designed to be fast and fully offline while remaining scalable for inventories of any size.

---

## Why Stocktopus?

Many inventory management solutions are either too complex, cloud-dependent or filled with features that most users never need.

---

## Features

- 📂 *Hierarchical locations*
- 🏷️ *Custom categories*
- 🔎 *Search*
- 🖼️ *Image support*
- 🔢 *Barcode & QR Code support*
- 💾 *SQLite database*
- 🖥️ *Gui interface*
- 🌍 *Multi languages support*
- 📊 *Stat and info dashboard*
- 🔄️ *Automatic and periodic backup*
- 🧰 *Import and export via csv*

---

## Database

Stocktopus stores all data using SQLite.

Current database entities include:

- 📂 Locations
- 📦 Items
- 🏷️ Categories
- 🔢 Item Codes
- 📜 Movement History
- 👤 Users (not implemented yet)

## Install STOCKTOPUS:

To install stocktopus please download the setup exe created by me,
it is a very easy and fast process:


[Download Stocktopus Setup](https://www.mediafire.com/file/t4emqpzhf3a8dyg/Stocktopus_Setup_1.0.exe/file)


If you prefer:
- clone this repository on your PC
- install all the required libraries in requirements.txt.
  ~~~
  pip install -r requirements.txt
  ~~~ 
- run the script.
  ~~~
  python main.py
  ~~~
